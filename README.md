# AI Bookmarks 🔖

智能书签管理 Chrome 扩展 - AI 驱动的书签收藏、摘要、分类和语义搜索。

## 功能特性

### ✅ 已实现功能

1. **一键收藏** - 快速保存当前页面，自动提取内容
2. **AI 智能摘要** - 自动生成 3 句话摘要，提取核心内容
3. **智能分类** - AI 自动识别内容类别（技术、产品、商业等）
4. **语义搜索** - 自然语言搜索，如 "那篇讲 SEO 的文章"
5. **每日回顾** - 智能推荐值得重温的收藏
6. **导入导出** - 支持 JSON 格式数据备份

## 安装方法

### 开发者模式安装

1. 打开 Chrome，访问 `chrome://extensions/`
2. 开启右上角的 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择本项目文件夹

### 配置 API Key（可选但推荐）

1. 点击扩展图标，打开设置 ⚙️
2. 输入 OpenAI API Key（获取地址：https://platform.openai.com/api-keys）
3. 保存设置

> 没有 API Key 也可以使用，但 AI 摘要和语义搜索功能会降级为基础模式

## 使用方法

### 收藏书签
1. 在任意网页点击扩展图标
2. 点击 **一键收藏** 按钮
3. AI 会自动分析页面，生成摘要和分类

### 搜索书签
1. 切换到 **搜索** 标签
2. 输入自然语言查询，如：
   - "那篇讲创业融资的文章"
   - "关于 React 性能优化的教程"
   - "上周收藏的设计资源"

### 浏览书签
1. 切换到 **书签** 标签
2. 使用分类筛选器过滤
3. 点击书签卡片查看详情

### 每日回顾
1. 切换到 **回顾** 标签
2. 查看 AI 推荐的值得重温的书签
3. 点击可标记为已回顾

## 技术架构

```
├── manifest.json      # Chrome 扩展配置
├── popup.html/js/css  # 弹窗界面
├── background.js      # 后台服务
├── content.js         # 内容提取脚本
├── storage.js         # IndexedDB 存储
├── ai-service.js      # AI 服务（OpenAI API）
└── icons/             # 扩展图标
```

### 技术栈
- **存储**: IndexedDB（本地存储，数据安全）
- **AI**: OpenAI GPT-3.5（摘要生成）+ text-embedding-3-small（语义搜索）
- **UI**: 原生 JavaScript + CSS（轻量快速）

## 数据安全

- 所有书签数据存储在**本地浏览器**中
- API Key 存储在 Chrome Sync Storage
- 不上传任何数据到第三方服务器（除 OpenAI API 调用）
